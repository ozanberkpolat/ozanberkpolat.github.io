**Azure Backup for Azure Cosmos DB** is generally available. Vaulted backup stores immutable, long-term backups in a logically air-gapped backup vault, isolated from the production environment. It complements the native Cosmos DB backup options.

Database and security teams that need ransomware protection or long retention for Cosmos DB accounts should care. Isolated, immutable copies help meet recovery and compliance requirements.

Check your Cosmos DB accounts against the retention and recovery rules you have. Set up a vault and a backup policy, then test a restore.
