**Geo-redundancy on App Service** is in public preview. App Service creates and manages resources across Azure regions, so you no longer build and maintain a separate deployment in each region yourself.

Architects running web apps with regional failure requirements should compare it with their current Front Door plus dual-deployment pattern. It could remove a lot of pipeline and configuration drift.

Test failover behavior, data dependencies and recovery objectives in a pilot app. Preview features usually have no production SLA, so keep the existing design until GA.
