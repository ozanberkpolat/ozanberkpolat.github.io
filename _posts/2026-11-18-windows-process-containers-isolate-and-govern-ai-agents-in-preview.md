Windows is adding **process container controls** to set boundaries around AI agents. They cover Component Object Model (COM) and Inter-Process Communication (IPC) governance, granular network policies and identity-proofing protections. The goal is for agent activity to be isolated, observed and governed. All of these updates are in preview.

Endpoint and security engineers should care. Agents that run on user devices inherit the user's reach by default, and these controls narrow what an agent process can touch.

Review which agents your teams run locally, and what they need to access. Test the container and network policy controls on a pilot device. Then align them with your Intune compliance and Defender protection plans for agents.
