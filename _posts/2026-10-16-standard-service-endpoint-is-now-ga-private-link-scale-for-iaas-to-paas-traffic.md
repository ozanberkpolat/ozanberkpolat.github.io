Connecting IaaS workloads to PaaS services privately has always meant trade-offs between manageability and scale. A new member of the Azure Private Link family aims to remove them, and it just reached general availability.

**Standard service endpoint** is described as a scalable and secure approach for connecting Azure IaaS workloads to Azure PaaS services. It targets the manageability and scale limitations that teams run into with the existing options, and it is now *Generally Available*, so it is ready for production designs.

If you own network architecture for PaaS-heavy environments, this is worth a close look. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=571025)
