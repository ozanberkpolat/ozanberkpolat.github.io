Microsoft Entra adds new capabilities for identity and access in the agentic era. One of them is **Agent ID for discovered local agents**, in preview, which automatically assigns an Agent ID to local agents that are discovered. The announcement also covers visibility and control over AI interactions and reducing identity security risk across the estate.

Identity and security engineers should care because developers already run coding agents on endpoints, and those agents act with the user's credentials. Giving them their own identity makes them visible and governable like other workload identities.

Review which local agents run in your environment. Then check whether your Entra tenant meets the preview requirements, and decide who owns the Agent ID lifecycle before you turn it on.
