**Stop letting rigid defaults slow down your database development.** In the fast-paced world of cloud engineering, every second counts. The latest update to the Azure SQL extension for Visual Studio Code is all about speed and personalization, ensuring your editor works exactly the way you do without the need for cumbersome menu navigation.

The core of this update brings deep **keyboard shortcut customization** directly to your fingertips. You can now map specific actions for Quick Queries, the Results Grid, and the Query Editor—all without ever leaving your editor. Whether you are a power user with complex macros or just looking to streamline your most frequent tasks, these enhancements eliminate friction and keep you in the "flow state."

> This update bridges the gap between database management and modern IDE flexibility, allowing developers to treat SQL tasks with the same efficiency as their primary application codebase.
