Windows 365 gets several updates. **Direct Stream** enhancements are GA for Cloud PC users, with more resilient connectivity and better multimedia over variable networks. With NVIDIA, GPU-enabled Cloud PCs will support up to two 4K streams at 60 frames per second. That part is in preview early next year in select regions.

The Windows 365 admin assistant is an AI-powered experience in Microsoft Intune, now in preview. It helps admins monitor Cloud PC health, investigate issues and find likely causes. Windows Mobile Application Management lets you apply security and data-protection policies to the Windows App.

Endpoint teams should enable the admin assistant in a pilot tenant and judge its troubleshooting output. Review MAM policies if users reach Cloud PCs from unmanaged devices.
