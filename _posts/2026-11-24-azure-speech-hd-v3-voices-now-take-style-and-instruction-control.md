Synthetic voices that all sound the same are a real limit for voice agents and narration. Azure Speech in Foundry Tools now lets you steer how HD V3 voices deliver a line, instead of accepting one fixed delivery.

**Style and instruction control for HD V3 voices is in public preview.** You use the supported controls to shape how the voice speaks. The article names voice agents and narration as target scenarios, but it also says the same controls apply to other speech experiences. As a preview feature, check the supported controls before you plan a production rollout.

If you build voice experiences on Azure, this is worth a few minutes. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=581353)
