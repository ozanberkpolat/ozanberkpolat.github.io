**Agent Grid** is in public preview. It brings identity-based Zero Trust network security to AI agents on supported Azure environments. Security teams can govern communication among agents, models, tools and external services through centrally managed policies.

This matters to network and security engineers who today control agent traffic with ad hoc firewall rules or none at all. Policy tied to agent identity is easier to audit than IP-based rules.

Check which Azure environments are supported, then pilot it on one agent workload. Map your current agent-to-tool and agent-to-model flows first so you can write policies against a known baseline.
