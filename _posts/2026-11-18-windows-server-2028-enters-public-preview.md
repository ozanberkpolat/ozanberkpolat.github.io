**Windows Server 2028**, the next Long-Term Servicing Channel release, is now in preview. Microsoft positions it as bringing together security, virtualization, hybrid cloud management and hybrid intelligence investments for mission-critical workloads, from the datacenter to the edge.

Infrastructure teams that plan server lifecycles should care. A new LTSC release sets the next upgrade target for fleets that now run 2016, 2019 or 2022, and it affects licensing and hardware planning.

Do not put it in production. Deploy it in a lab and test your core roles, agents and backup tooling against it. Then add it to your upgrade roadmap once Microsoft publishes the general availability date.
