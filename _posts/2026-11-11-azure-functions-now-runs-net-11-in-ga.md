If you run serverless workloads on Azure, your runtime upgrade path just got clearer. **Azure Functions support for .NET 11 is now generally available**, so you can move to the newest .NET without leaving the platform.

You can build Azure Functions apps that target .NET 11 using the *isolated worker model*, while keeping the familiar Azure Functions programming model and host integration. In short, your existing serverless approach stays the same, and the runtime underneath moves forward. This is a GA release, so it is ready for production planning.

Planning your next framework upgrade? Check what changes for your apps. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=578773)
