---

Azure Database for MySQL now lets you **rename a server** in place. You no longer need to recreate the server or migrate data just to adopt a new naming standard.

Database and platform engineers who manage many MySQL instances benefit most. It helps when you align names with a new convention or fix early naming mistakes.

The server name is part of the connection endpoint. Before you rename, list every application, connection string, DNS record and private endpoint that uses the old name, and update them as part of the change window.
