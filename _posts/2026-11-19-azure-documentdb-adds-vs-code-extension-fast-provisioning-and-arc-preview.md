Azure DocumentDB gets five updates. The **Visual Studio Code extension** is GA and lets developers connect to clusters, browse collections, inspect documents and run queries. Near-instant cluster provisioning is also GA for M10 through M30 clusters, which helps agents and test pipelines that create environments often.

Two previews target hybrid and sovereignty needs. DocumentDB enabled by Azure Arc extends MongoDB-compatible workloads to hybrid and multicloud environments. DocumentDB on Azure Local runs it on your own infrastructure. Both fit data residency and infrastructure-control requirements.

If you run MongoDB-compatible workloads on premises, check the Arc and Azure Local previews against your residency rules. For dev and test, try the faster provisioning on small clusters.
