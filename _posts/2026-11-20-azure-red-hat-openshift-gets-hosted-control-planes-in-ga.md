**Hosted control planes** for Azure Red Hat OpenShift are generally available. The OpenShift control plane is separated from the worker nodes that run your applications, and it is managed outside your worker footprint.

Platform teams that run OpenShift on Azure should evaluate the cost and operational effect, since fewer control plane resources live in your subscription.

Check whether it can be used for new clusters only or also for existing ones. Plan a pilot cluster and review networking and upgrade behavior.
