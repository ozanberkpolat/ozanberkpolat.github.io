**Azure Multicloud Interconnect** is a managed service for private connectivity between Azure and other cloud providers. It is generally available. Amazon Web Services support is GA, and Google Cloud Platform support is in public preview.

Network architects running workloads across clouds should look at it. It can replace self-built VPN or partner-routed links between Azure and AWS or GCP with a managed private path.

Check which regions and bandwidth options apply to your design. Compare it with your current cross-cloud links on cost and operations. Treat the Google Cloud side as preview until it reaches GA.
