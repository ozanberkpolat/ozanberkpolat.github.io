If you run Azure Database for PostgreSQL Flexible Server, your compute options just got a meaningful upgrade. The **v6 generation of Intel and AMD compute tiers** is now generally available, and it comes with a local temporary disk.

The new v6 tiers expand the Flexible Server compute portfolio with higher performance and larger scale. The local temp disk is the notable addition for workloads that lean on temporary storage, such as sorts, hash operations and other query spill. This is a **GA release**, not a preview, so it is ready for production planning.

Worth a look before your next sizing or migration review. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=579590)
