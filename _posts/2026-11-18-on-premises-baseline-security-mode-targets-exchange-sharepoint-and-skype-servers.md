Microsoft started an on-premises security initiative, beginning with supported Exchange Server, SharePoint Server and Skype for Business Server. It combines guidance, migration support and product changes. **On-Premises Baseline Security Mode** builds Microsoft's recommended security settings into these server products to cut manual setup and upkeep.

The work covers faster security updates that reach connected servers, easier safe configuration, and temporary protections against emerging threats until a permanent update ships. Some protections and guidance exist today, including security updates and hardening guidance. More guidance is coming to Secure Now.

Teams still running these servers should inventory them and check patch level against current guidance. Plan which workloads can move to Microsoft 365 and which must stay.
