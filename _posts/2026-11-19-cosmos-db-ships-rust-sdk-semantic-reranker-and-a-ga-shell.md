Azure Cosmos DB announced seven updates. The **Azure Cosmos DB Shell** is generally available in Visual Studio Code and the Azure portal, with MCP integration for AI-assisted work. The Rust SDK is generally available. The semantic reranker, which reorders search candidates by meaning and context, is also generally available. An AI-assisted data modeler for partition keys and container settings is in the VS Code extension preview.

Teams building retrieval or agent workloads on Cosmos DB should care, since reranking improves result quality without changing the index. Rust services get a supported native client.

Try the semantic reranker on an existing search workload and compare relevance. Evaluate the Rust SDK for latency-sensitive services, and use the data modeler preview when designing new containers.
