HTTP-layer DDoS attacks remain a leading cause of application downtime, and **static controls such as IP filters and fixed rate limits** often struggle to keep up with them. If you front your apps with Azure Front Door, this announcement is worth your attention.

Microsoft has announced the **general availability of the HTTP DDoS ruleset for Azure Web Application Firewall (WAF) on Azure Front Door Premium**. It is no longer a preview feature, so it can be considered for production workloads that sit behind Front Door Premium and need protection beyond manual filters.

Curious how the ruleset works and how to enable it? [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=578681)
