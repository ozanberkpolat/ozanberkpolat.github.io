**Azure AI Gateway** was previously the AI Gateway tier of API Management. It is now generally available as a fully managed Azure service that connects users, applications and agents to AI models and MCP tools across providers.

Related GA releases include the Microsoft Agent 365 integration with API Management and AI Gateway, which enforces security and access policies at runtime, and the Unified Model API, which standardizes access to models from multiple providers.

Platform teams that front AI models through API Management should review how the new service is packaged and billed. Plan a central entry point for model and MCP traffic, and decide where policies like access control and agent governance will live.
