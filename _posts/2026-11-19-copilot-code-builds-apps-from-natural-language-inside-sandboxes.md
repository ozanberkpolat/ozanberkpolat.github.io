**Copilot Code** lets people build dashboards, trackers and apps with natural language, using the agentic technology behind GitHub Copilot. Cloud projects run in a secure sandbox and stay within the tenant. A local sandbox limits what Code and anything it runs can read, write and reach on the network. It is available on Windows now and coming to macOS. Supported apps can be published through Copilot Managed Runtime, and they appear in the Microsoft 365 admin center. It is in the Frontier program now, with general availability planned for December.

Microsoft 365 admins and security teams should care, since citizen-built apps will arrive with their own data access.

Decide who gets access in the Frontier program, review the sandbox network settings, and plan how published apps are governed in the admin center before general availability.
