**Advanced load balancing** for Azure Application Gateway is in public preview. It gives you more control over how traffic spreads across backends that serve different workloads, including AI applications and ordinary web traffic. New server-level controls are part of the release.

Architects who front mixed backends, such as inference endpoints with uneven request costs next to web apps, should care. Plain round-robin often fits these backends poorly.

Try it on a test gateway with a representative backend pool. Compare backend utilization and latency against your current algorithm before you change production routing.
