**Dynamic Agent Risk**, in preview, combines runtime signals from identity, access, data, endpoints, cloud and network with posture and blast radius into one risk assessment per agent. The score updates as an agent takes new actions, becomes a malicious target or receives code or model updates. It is visible across the Microsoft 365 admin center, Defender, Entra, Intune and Purview.

Partners Check Point, Cyera, Darktrace and Zenity will send agent-security signals into Microsoft Sentinel through dedicated connectors and an agreed data schema. Sentinel analytics rules turn them into alerts, which Microsoft Security correlates to agents.

Security teams should inventory the agents they run and check which of the named partner tools they already use. Plan Sentinel connector onboarding and decide how agent risk levels will feed your triage and access decisions.
