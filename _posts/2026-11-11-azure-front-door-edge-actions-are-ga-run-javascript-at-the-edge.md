What if you could make routing and content decisions in the request path itself, without standing up a separate compute tier behind your CDN? **Azure Front Door edge actions** are now generally available, bringing serverless compute to the edge.

With edge actions, you run *lightweight JavaScript functions* during Azure Front Door client request and response processing. That lets you make real-time decisions as traffic flows through, instead of pushing that logic back to your origin. The feature is GA, so it is ready for production planning rather than just experimentation.

If you run internet-facing workloads behind Front Door, this is worth a close look. The announcement has the details you need to judge where it fits. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=579310)
