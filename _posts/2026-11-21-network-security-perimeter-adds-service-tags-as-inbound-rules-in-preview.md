**Service tags as inbound rules** in network security perimeter are in public preview for third-party customers. They simplify access management for perimeter-protected resources, because you can allow traffic by tag instead of maintaining lists of IP ranges.

Security and platform engineers who run PaaS resources inside a perimeter and keep long lists of provider IP addresses should care. Tags are maintained by the provider, which reduces stale rules.

Find inbound rules built from manually copied IP ranges and test replacing them with service tags. Check which tags are supported in the preview before you plan the change.
