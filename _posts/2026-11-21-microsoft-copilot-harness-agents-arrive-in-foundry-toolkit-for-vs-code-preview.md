Agent Builder in the Microsoft Foundry Toolkit for Visual Studio Code now supports prompt agents that run on the **Microsoft Copilot harness**. This is in public preview. Developers can configure tools and skills, edit local YAML definitions, deploy changes to Foundry and run the agent from the same editor.

Teams building agents on Foundry should care, especially if they want agent definitions kept as YAML in source control. Local editing with deployment from VS Code fits a normal review and release process for agent changes.

Try it in a non-production Foundry project first. Check which tools and skills the harness supports, and confirm your governance policies apply to these agents. Preview features can change, so hold off on production workloads until the feature is generally available.
