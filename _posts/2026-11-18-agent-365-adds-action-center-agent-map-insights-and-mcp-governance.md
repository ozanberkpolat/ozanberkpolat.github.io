Microsoft Agent 365 adds governance features for the agent estate. A new action center, expected in private preview in December, surfaces inactive and ownerless agents for review and cleanup. Business use-case and task classification in Agent Map, in preview, helps find agents doing similar work so you can retain or consolidate them.

**Plugins and skills governance** for Copilot and Cowork is generally available. Admins manage availability centrally and assign access to specific users and groups from the Microsoft 365 admin center. Governance for MCP servers and tools is also expanding, including servers from Azure AI Gateway and third-party gateways.

Admins should turn on plugins and skills governance now and review which plugins are open to everyone. Plan an ownership check for agents so the December action center has clean data to work with.
