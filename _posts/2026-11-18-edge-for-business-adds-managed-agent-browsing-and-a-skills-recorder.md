Edge for Business adds controls for human and agent browsing. A **managed agent browsing** experience lets IT require Edge for Business whenever Microsoft or third-party agents need a browser. Each agent works in a dedicated window with its own Microsoft Entra agent identity, within the user's existing permissions and policies, with visual cues marking agent windows.

Skills recorder, in preview with Cowork, lets employees record a workflow and turn it into a reusable skill that runs the same steps each time. IT controls when it is enabled.

Browser and identity admins should review policies for agent browser use and decide who may record skills. Test agent identity behavior in a pilot group before wider rollout.
