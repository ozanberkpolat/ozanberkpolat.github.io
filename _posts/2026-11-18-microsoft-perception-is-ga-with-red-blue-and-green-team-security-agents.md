**Microsoft Perception**, formerly Project Perception, is generally available, including the agents and playbooks announced in July. Red team agents look for weaknesses, blue team agents triage and investigate, and green team agents help prioritize exposure. Playbooks orchestrate several agents for broader tasks.

The Triage Agent now covers about 80% of alerts in a typical Defender queue and handles AWS and Salesforce alerts. The Investigation Agent follows attacks across endpoints, identities, email, Active Directory and cloud resources, and can reason over AWS and Okta data.

Security operations teams should run it on a slice of the alert queue and compare triage results with analyst decisions. Review which third-party sources you need connected before widening scope.
