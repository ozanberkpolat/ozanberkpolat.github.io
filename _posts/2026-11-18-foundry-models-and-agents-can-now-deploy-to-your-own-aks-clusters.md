Microsoft Foundry will let teams deploy open-weight models and agents to their own **Azure Kubernetes Service** clusters. The deployment uses the infrastructure, security policies and governance you already have. Teams choose GPUs and regions based on cost, latency and data residency, and Foundry handles setup so the developer workflow stays the same from experiment to production.

The wider Azure announcement covers production AI infrastructure across compute, storage and networking, including agent networking and security, isolation, confidentiality, context and state.

Platform teams that already run AKS should check GPU quota and regional capacity, and decide which policies must apply to model workloads. Pilot with one open-weight model before moving agent workloads across.
