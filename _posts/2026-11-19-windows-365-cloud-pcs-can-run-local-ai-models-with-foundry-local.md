Windows 365 Cloud PCs now support running current local AI models, with sizes up to 32 vCPU and GPU-enabled options for development and AI workloads. This is generally available. With **Foundry Local**, developers run compatible models directly on a suitably sized Cloud PC at a predictable subscription cost. Windows Server 2025 with AVD Hybrid, in private preview, adds multi-user AI development environments on infrastructure you manage.

Endpoint and desktop architects should care when data must stay inside managed environments, or when inference cost on usage-based APIs is hard to predict.

Pick a pilot group of developers, size Cloud PCs against the models they need, and compare the subscription cost with API spend. Ask Microsoft about the AVD Hybrid private preview if you need self-managed hosting.
