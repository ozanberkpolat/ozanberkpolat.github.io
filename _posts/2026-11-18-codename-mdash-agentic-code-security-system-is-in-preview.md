**Codename MDASH** is Microsoft's agentic code security system, now in preview for eligible organizations. It uses more than 100 specialized AI agents in a four-stage pipeline: map the attack surface, scan code, validate findings through agent debate, then remove duplicates and, where possible, reproduce each finding with a triggering input.

New in this release: fewer false positives, repository sharding that splits large codebases into logical units to use fewer tokens per scan, clearer scan progress, and support for more of the MAI Cyber model family, including MAI Cyber 1.1 Flash. MAI-Cyber-2 will be used once evaluation testing is complete.

Security and engineering teams that triage large volumes of static analysis results should look at it. Check whether your organization is eligible, then pilot it on one large repository and compare validated findings and triage time against your current scanner.
