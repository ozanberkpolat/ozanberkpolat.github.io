Microsoft is expanding **agentic operations** across Azure Monitor, Azure Copilot and Azure SRE Agent. Natural language capabilities in Azure Monitor for planning and deploying cloud workloads are now generally available. Azure Copilot spaces and custom skills are in preview, and let teams tailor agents that carry persistent context.

Azure SRE Agent gains customer-managed keys for agent data, plus Entra Agent ID and Agent 365 integration so agents can be discovered, governed and audited like other identities. Azure Workload Center, in private preview, extends agentic monitoring and configuration validation to Oracle and SAP.

Operations and platform teams should review which of these fit their incident workflow. Start by testing the preview features in a non-production subscription, and check how agent identities and key control map to your existing governance rules before you grant agents any write access.
