**Azure Catalyst** is now generally available as a single experience for discovery, planning, migration and modernization across Azure and GitHub. The Azure Catalyst agent, formerly the Azure Copilot migration agent, is GA. New preview capabilities extend it from migration planning into deeper modernization and execution.

Enhancements include richer estate insights, AI-powered application discovery, modernization strategy with cost comparisons, and planning across applications, databases, storage and networking. Execution is handled through Azure Copilot and GitHub Copilot.

Teams running migration programs or planning application and database modernization should look at it. Run the discovery on a representative slice of your estate first, and compare its strategy and cost output with your current migration plan before you adopt it more widely.
