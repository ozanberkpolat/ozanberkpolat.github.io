**Autopilot** is Microsoft's first enterprise-grade, long-running agent for personal productivity. It runs inside the tenant with its own identity, memory and tool access. It can follow up on threads, run recurring work and continue a project without a new prompt. Colleagues can @mention a person's Autopilot in a Teams channel or group chat to request information or supported actions.

Actions it takes, even on a user's behalf, are tied to its own agent ID and safety-checked. Admins can see and manage it. Security and identity engineers should note that this adds a new non-human actor with delegated access to mail, files and chats.

It is rolling out through the Frontier program and appears in the left navigation of the Copilot app. If you run a Frontier tenant, review how agent identities are governed and what tool access Autopilot gets before enabling it for pilot users.
