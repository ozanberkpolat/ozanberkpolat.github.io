**Database Agent** is in public preview for Azure Database for PostgreSQL. It watches database health, combines metrics and configuration, and helps detect, explain and respond to performance issues faster.

DBAs and platform teams running PostgreSQL on Azure should care, especially those with limited on-call depth.

Enable it on a non-production server, compare its findings with your current monitoring, and check what permissions it needs before wider use.
