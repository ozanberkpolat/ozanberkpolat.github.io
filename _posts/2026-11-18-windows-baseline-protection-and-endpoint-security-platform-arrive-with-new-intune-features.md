The new **Windows Endpoint Security Platform** is generally available. It gives approved security products a safer way to protect devices while improving reliability. Windows baseline protection, in private preview, applies and maintains critical security settings from boot, enforcing hardware-rooted security and integrity features.

Intune and Windows Autopatch will support Windows Server 2028 for client-like scenarios in private preview. Enterprise App Management will expand automatic updates to all Windows applications, not only those IT deployed, also in private preview. Declarative device management is in preview.

Endpoint teams should ask their security vendors about support for the new platform. Request access to the private previews that match your patching and app update pain points, and test them on a pilot ring.
