**Microsoft Copilot SDK 2.0** is generally available. It embeds the Copilot agent harness in your own applications, now on a native Rust runtime. It supports multi-tenant, high-scale deployments with enterprise security controls, and works across six programming languages. It is the same harness used in production across Microsoft and GitHub.

Developers and architects building agents inside line-of-business or SaaS applications should care, especially where tenant isolation and scale matter.

Review your current agent hosting approach and compare it with the SDK for multi-tenant cases. Check the supported languages against your stack, and test isolation and throughput in a pilot before migrating.
