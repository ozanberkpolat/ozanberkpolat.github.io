The **Agent Sandbox** cluster extension gives Kubernetes teams isolated environments for AI agents that run untrusted, model-generated code. Today teams assemble their own sandbox lifecycle, storage and warm-up logic. The extension aims to replace that custom work.

Platform engineers building agent platforms on AKS should evaluate it. It pairs with the pod snapshot extension, which keeps in-memory state across restarts of sandboxed workloads.

Enable the extension on a test cluster and compare it with your homegrown sandbox setup for isolation, startup time and operational effort.
