Digging through raw WAF logs to work out why a request was blocked is slow, and it gets worse as traffic grows. If you run **Azure Application Gateway** with Web Application Firewall, that routine just got easier.

**WAF Insights** is now *generally available*. It is a built-in experience in the WAF policy that brings WAF logs and metrics together in interactive dashboards, so you can investigate blocked requests and understand what your WAF is doing without stitching queries together yourself.

Worth a look if you tune WAF rules or triage security events. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=579280)
