**Fabric HorizonDB** is a preview PostgreSQL offering inside Microsoft Fabric. It is serverless: databases provision in seconds, scale with demand, pause when idle and resume on the next query. That suits agents that create short-lived databases for prototypes and experiments.

It will also be enabled for Fabric apps as a managed backend with data APIs, authentication, storage and hosting. Live operational data can be queried together with analytics data in OneLake, which supports translytical queries from a single PostgreSQL endpoint.

Data and application architects should not confuse it with Azure HorizonDB, which is a separate service. Try it for bursty or agent-created workloads, and test how queries across operational data and OneLake perform.
