Microsoft Defender now offers agent-native **runtime protection** on Windows for local AI agents, and it is generally available. Covered agents include Claude Code, GitHub Copilot CLI, the GitHub Copilot app, Claude Desktop (Code) and the VS Code GitHub Copilot extension. It aims to detect and stop malicious instructions while the agents operate on endpoints.

Endpoint security teams should care. Coding agents read files, run commands and follow instructions from content they process, so prompt injection becomes an endpoint risk.

Check your Defender for Endpoint licensing and the supported agent list. Enable the protection on a pilot group of developer machines and review the detections it raises before wider rollout. It pairs with the Intune preview that can mark devices with unapproved agents as noncompliant.
