**Windows 365 for Agents** gives computer-using agents managed Cloud PCs, which helps with legacy apps that have no APIs. It is now eligible for Copilot Credits, so billing, governance and cost reporting sit with other AI services.

In Copilot Studio it is available as a computer-use tool in the Standard harness, with the Microsoft Copilot harness in preview in December. Foundry builders get a Windows 365 for Agents MCP server in preview early next year. Persistent Cloud PCs are also introduced.

If agents must drive legacy desktop apps, list those apps now and check the governance and network needs of the Cloud PCs they would run on. Plan a pilot once the Foundry MCP preview opens.
