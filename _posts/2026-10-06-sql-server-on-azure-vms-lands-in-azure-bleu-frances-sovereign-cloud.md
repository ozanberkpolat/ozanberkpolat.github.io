If your SQL Server workloads have to stay inside French sovereign boundaries, there is a new option. **SQL Server on Azure Virtual Machines is now generally available in Azure Bleu**, so you no longer need to choose between running the engine you know and meeting strict sovereignty rules.

The announcement says you can deploy and manage SQL Server workloads on Azure VMs in France's sovereign cloud environment, while meeting data residency and sovereignty requirements. This is a *GA* release, not a preview, and it gives regulated teams in France a familiar IaaS path for their databases.

Planning a migration or a new deployment in Azure Bleu? Check the details before you design. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=571499)
