**Microsoft IQ** is now generally available. It groups enterprise context management (Work IQ, Fabric IQ, Foundry IQ and Web IQ, plus reusable business plugins, skills, tools and agents) with continuous improvement in Microsoft Foundry. The goal is that what agents learn is reused as models, tools and business needs change.

Microsoft says it is built on products customers already use, with no new SKU or subscription. It is paired with Agent 365 for governance. Architects designing agent platforms should care, because it sets how grounding data and shared skills are organized across apps.

Check which IQ components your current agents already use. Then decide which business context and skills should become shared plugins instead of being rebuilt per agent.
