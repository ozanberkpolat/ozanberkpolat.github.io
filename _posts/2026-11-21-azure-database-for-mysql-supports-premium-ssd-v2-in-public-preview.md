Azure Database for MySQL now supports **Premium SSD v2** managed disks in public preview. Microsoft states it offers better price-performance than Premium File Share. You can scale storage capacity and other performance settings independently.

Database owners who pay for oversized storage to reach a performance target should care.

Create a test server on Premium SSD v2 and compare cost and performance with your current setup. Check region availability and preview limits before planning a migration.
