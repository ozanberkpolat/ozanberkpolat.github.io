**Azure Firewall for Containers** extends Azure Firewall protection to containerized workloads. It gives you a central way to secure network traffic for container environments, using Azure Firewall capabilities as part of your container networking.

Network and security engineers who run container platforms and today manage egress and east-west controls with separate tooling should look at it. A single policy point can reduce drift between container and VM network rules.

This is a preview, so test it in a non-production cluster first. Check which container platforms and traffic patterns it covers, and compare the rule model with your current setup before you plan a migration.
