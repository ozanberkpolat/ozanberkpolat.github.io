**Azure DDoS Protection** now covers the public IPs behind Azure NAT Gateway StandardV2, in public preview. Both IPv4 and IPv6 addresses that carry outbound internet traffic can be protected from network-layer attacks, with the same DDoS Network Protection used elsewhere.

Network and security engineers who use NAT Gateway v2 for outbound traffic should care. Outbound IPs were an easy gap in DDoS coverage reviews.

List the NAT Gateway v2 public IPs in your estate and check whether they sit under a DDoS protection plan. Enable protection in a test environment first and confirm the cost impact.
