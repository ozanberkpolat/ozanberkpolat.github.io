categories: [News, "Networking"]

---

Application Gateway now has centralized **user authentication** in public preview. It signs users in with OpenID Connect before traffic reaches the backend. The preview also updates the JWT validation experience.

Network and application security engineers can use it to move sign-in and token checks out of each app and into the gateway. This gives one place to enforce authentication.

Try it with one internal app and an existing identity provider. Check how it interacts with your WAF rules and backend session handling before wider use.
