The **Unified Model API** in Azure API Management is generally available. It is a standard way to connect applications to AI models from multiple providers without handling a different API interface and integration for each one.

Platform and application teams that use more than one model provider should care, because it can reduce provider-specific client code and keep policy in one gateway.

Put an existing multi-model application behind it in a test instance and check how it fits with your current API Management policies for auth, limits and logging.
