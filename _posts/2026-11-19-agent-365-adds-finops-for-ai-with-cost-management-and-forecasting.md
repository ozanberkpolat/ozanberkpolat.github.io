Agent 365 now includes **Cost Management** in the Microsoft admin center. It gives one place to see usage-based AI spend across Copilot Cowork, Copilot Code, GitHub Copilot CLI, Copilot Studio, Copilot Managed Runtime, Autopilot and Work IQ APIs. Admins can set spending policies, limits and alerts, and send data to Microsoft Fabric for custom chargeback. This part is in preview. Forecasting, plain-language questions and optimization recommendations are available in the Frontier program this month, with value insights expanding in December.

FinOps leads and platform owners should care, because AI consumption is spread across many services with separate meters.

Enrol a pilot tenant in the Frontier program, map your AI services to cost owners, and define limits and alerts before agent usage grows. Plan the Fabric export if you need chargeback by department.
