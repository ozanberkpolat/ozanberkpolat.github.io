Agent 365 usage and activity insights in the Microsoft Admin Center now cover Microsoft pre-built agents and agents built on Microsoft platforms, whatever the Agent 365 licensing status. This is GA. It exposes the agent overview, active users, sessions, exception rate and run time.

Viva Insights drops its Agent 365 license requirement for agent insights. It still needs at least 50 assigned Copilot licenses. Eligible organizations can export the data and query it.

Admins get baseline visibility for free, so check the Admin Center now to see which agents are used. Enterprise-grade management, governance and security still need an Agent 365 or ME7 license, and the usage data helps you decide where that is worth buying.
