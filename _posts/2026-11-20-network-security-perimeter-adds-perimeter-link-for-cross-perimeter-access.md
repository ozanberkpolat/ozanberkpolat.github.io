**Perimeter link** is in public preview for network security perimeter. It allows secure connectivity between resources protected by different perimeters, while perimeter-based access control stays in force.

Network and security engineers who split PaaS resources across several perimeters, for example per environment or business unit, were blocked by this gap. Now cross-perimeter flows can be allowed without opening public access.

Map which perimeters need to talk to each other and pilot links in transition or learning mode. Review the logs before you enforce.
