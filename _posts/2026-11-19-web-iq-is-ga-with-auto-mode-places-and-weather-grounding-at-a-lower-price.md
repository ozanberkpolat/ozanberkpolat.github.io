**Web IQ** is GA for all Azure customers. It gives agents and applications fresh knowledge from web pages, news, images and videos, at a new lower price. Auto mode combines Web, Images, Videos, News and the new Places and Weather categories in one call, so developers no longer pick and orchestrate separate APIs.

Auto Advanced is a further option for harder questions. When the first result is not enough, it evaluates the response, refines the query and retrieves more information.

Teams that build web grounding by hand should compare Auto mode on quality, latency and cost. Check data handling rules before sending enterprise prompts to a web grounding service.
