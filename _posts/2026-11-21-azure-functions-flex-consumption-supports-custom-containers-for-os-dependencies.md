Flex Consumption apps used to run in a Microsoft-managed worker environment that you could not extend. **OS-level dependency support via containers** is now in preview. It lets you bring native executables and system libraries to the app.

Teams that stayed off Flex Consumption because of native libraries or system packages should re-evaluate it.

Try a function that needs such a dependency in a test app. Review the preview limits before moving any production workload.
