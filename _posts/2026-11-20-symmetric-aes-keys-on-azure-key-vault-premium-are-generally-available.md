title: "Symmetric AES Keys on Azure Key Vault Premium Are Generally Available"
date: 2026-11-20
categories: [News, "Security"]
tags: ["azure", "ignite 2026", "key vault", "hsm", "aes"]
---

Symmetric encryption with the oct-HSM key type and the AES algorithm is now generally available in **Azure Key Vault Premium**. It builds on the public preview from July 2026.

Security engineers and partners who need HSM-protected symmetric keys can use them directly in Key Vault. This reduces the need for separate key management for symmetric workloads.

Review any applications that keep AES keys outside an HSM. Plan a move to Key Vault Premium where the policy requires hardware protection.
