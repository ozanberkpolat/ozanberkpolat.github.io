If you automate Azure Database for PostgreSQL with ARM templates, Bicep or Terraform, you now have a new stable API version to pin to. No more building production tooling on preview versions.

The **Flexible Server REST API version 2026-10-01 is generally available**. This stable release expands what you can manage through the API: **maintenance management**, **immutable backups** and **multi-tenant encryption** with cross-tenant customer-managed keys. That covers operations, data protection and compliance in one version bump.

Worth a look before your next infrastructure-as-code update. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=579300)
