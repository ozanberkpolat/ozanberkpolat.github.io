Moving big, production-scale workloads into confidential computing has often meant compromising on the OS disk. That gap just closed: **Large OS Disk Encryption (LOSDE)** is now generally available for Azure Confidential VM migration scenarios.

The key takeaway is that larger workloads can now move into confidential computing with the OS disk *fully protected*, instead of being held back by disk size constraints. If you have been postponing a lift-and-shift of a heavy VM because of this limit, this is the status change to look at. The announcement is marked **Generally Available**, so it is ready for production planning.

Planning a confidential VM migration? Check the details before you size your next move. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=578850)
