**Copilot Managed Runtime** is generally available. It gives Microsoft-managed hosting and execution for apps built in Copilot Code, Copilot Cowork, Copilot Studio or compatible third-party tools, with a common way to host, run and govern them.

GA adds an optional data backend from Microsoft Fabric, covering database, storage and data APIs for apps that need persistence. The runtime keeps the hosting and enterprise management layer.

M365 and platform admins should decide who may publish apps to the runtime and how those apps show up in the admin center. Review data placement before allowing apps to use the Fabric backend.
