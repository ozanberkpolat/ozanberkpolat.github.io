You can now try **PostgreSQL 19** on Azure Database for PostgreSQL Flexible Server. The preview is limited to the East Asia region. You can create new servers through the Azure portal and Azure CLI to test the major version.

Database teams that plan major version upgrades should care. Early testing finds extension and application compatibility problems sooner.

Provision a test server in East Asia and run your application test suite against it. Do not use the preview for production data.
