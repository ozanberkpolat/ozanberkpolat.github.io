If your PostgreSQL workloads on Azure have been waiting for a closer or additional region, there is news: **East US 3** is now on the map.

Azure Database for PostgreSQL flexible server is **generally available** in the East US 3 region. You can now deploy new flexible server instances there, which opens up options for data residency, latency and regional placement. The announcement is short and does not list further details, so check the original for specifics.
