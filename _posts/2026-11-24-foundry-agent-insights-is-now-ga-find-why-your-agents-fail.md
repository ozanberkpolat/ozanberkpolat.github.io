Debugging an AI agent trace by trace does not scale. Once agents run in production, the real question is which failures keep coming back and which one to fix first.

**Agent insights in Microsoft Foundry** is now *generally available*. It analyzes agent traces, surfaces recurring patterns and groups related issues together. You can open an insight, review the supporting traces behind it, investigate the common failures and decide what to improve first. The article also points to the agent optimizer, which lets you test potential fixes.

If you build or operate agents on Foundry, this turns raw traces into a prioritized to-do list. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=581363)
