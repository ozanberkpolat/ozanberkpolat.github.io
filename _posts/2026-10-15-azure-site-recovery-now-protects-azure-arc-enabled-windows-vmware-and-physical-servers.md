If you manage on-premises Windows servers through Azure Arc, your disaster recovery story just got simpler. **Azure Site Recovery (ASR) is now generally available** for Arc-enabled Windows VMware virtual machines and physical servers.

The key point is that you don't have to pick between tools. You can protect Arc-managed machines with ASR while *continuing to use Azure Arc* for governance and inventory. The scope per the announcement: Windows VMware VMs and on-premises physical servers that are already Arc-enabled.

Worth a look if you run hybrid estates and want DR without changing how you manage them. [Dive into the full technical breakdown here](https://azure.microsoft.com/updates?id=576214)
