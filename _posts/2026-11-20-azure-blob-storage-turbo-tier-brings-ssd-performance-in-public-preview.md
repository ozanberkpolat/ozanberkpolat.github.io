The **turbo tier** for Azure Blob Storage is in public preview. It brings SSD-backed performance to performance-sensitive data in eligible Blob Storage accounts. It targets AI training, inference, analytics and other demanding data workloads.

Storage and data platform architects should care if object storage throughput limits GPU or analytics jobs. It may remove the need for a separate high-performance storage layer.

Check which accounts are eligible and what the tier costs. Run a benchmark with a real dataset before you plan any migration.
