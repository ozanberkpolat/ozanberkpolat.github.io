**Azure HorizonDB** is now generally available. It is a fully managed, PostgreSQL-compatible database service with enterprise security, resilience and scale, plus built-in vector search and AI capabilities. Supporting updates are also GA: geo-redundant backup and restore, private endpoint support, Microsoft Entra authentication, user-assigned managed identity, pgAudit auditing, Azure Advisor integration and availability in 15 regions.

Database and application architects running PostgreSQL on Azure should care. It is a separate service from PostgreSQL Flexible Server, and Database Migration Service can migrate to it in preview.

Compare it with Flexible Server for one candidate workload. Check region availability, private networking and encryption needs first. Customer-managed key encryption is still in preview.
