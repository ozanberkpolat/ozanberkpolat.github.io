**Redis 8** is now in public preview on Azure Managed Redis. It brings richer queries, atomic JSON updates, field-level expiration and finer-grained security to the managed service.

Application teams that use Redis for caching or as a JSON store may be able to drop custom code for those cases.

Deploy a test cache on Redis 8 and run your client libraries against it. Check compatibility with your current version before you plan an upgrade.
