**AI Security** is a new add-on for Azure Firewall Premium, announced at Ignite and now in public preview. It adds five capabilities aimed at protecting AI applications, safeguarding sensitive data, and strengthening malware and application defenses.

Network and security teams that already run Firewall Premium as the central egress and inspection point should look at it. It lets AI traffic be controlled at the same layer as the rest of the network, instead of in each application.

Check the full list of the five capabilities in the preview documentation, then test the add-on in a non-production hub with real AI application traffic before planning any rollout.
