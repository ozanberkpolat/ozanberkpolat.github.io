# blog.obp.com.tr

Ozan Berk Polat's Azure blog. Astro static site, deployed to GitHub Pages by `.github/workflows/pages-deploy.yml`.

- Posts live in `_posts/YYYY-MM-DD-slug.md` and are served at `/posts/<slug>/`.
- Posts in the `News` category are the automatic Azure Radar notes (`/radar/`); everything else is an article.
- `npm run dev` for a local server, `npm run build` for `dist/` plus the Pagefind search index.
